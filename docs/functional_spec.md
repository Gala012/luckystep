# 吉星记步 - 功能需求文档

## 1. 项目概述

**应用名称**：吉星记步（Lucky Star Pedometer）

**核心理念**：精准计时助你掌握每分每秒，逐步实现开启运动新旅程；轻松打卡保持水分充足，轻松记录管理水分摄入。

**技术架构**：Flutter + GetX + MVC

**数据存储**：本地 SQLite（sqflite/drift），无网络请求

**平台**：iOS + Android 双端

---

## 2. 核心功能模块

### 2.1 记步（步数统计）
- **功能描述**：记录每日步数，展示当日步数、目标完成进度
- **交互**：首页展示步数卡片；支持设置每日步数目标；后台/前台持续计步
- **数据**：步数记录表（日期、步数、目标步数）

### 2.2 精准计时
- **功能描述**：计时器/倒计时，助用户掌握每分每秒
- **交互**：支持正计时、倒计时；开始/暂停/重置；可设置目标时长
- **数据**：计时记录表（开始时间、结束时间、时长、类型）

### 2.3 水分摄入
- **功能描述**：记录每日饮水量，管理水分摄入，保持水分充足
- **交互**：添加单次饮水量（杯/毫升）；设置每日目标；查看当日完成进度
- **数据**：饮水记录表（日期、饮水量、目标量）

### 2.4 打卡
- **功能描述**：每日轻松打卡，养成运动与饮水习惯
- **交互**：每日一键打卡；打卡日历展示连续打卡天数
- **数据**：打卡记录表（日期、是否打卡）

### 2.5 运动旅程
- **功能描述**：基于步数、打卡、饮水等数据，展示用户的运动新旅程
- **交互**：展示累计步数、连续打卡天数、饮水达标天数；简单进度可视化
- **数据**：聚合统计，来源于上述各表

---

## 3. 创新功能（3-5 个）

- **成就徽章**：达成步数目标、连续打卡、饮水达标等解锁徽章，增强成就感
- **周/月统计图表**：步数、饮水量的折线图/柱状图，直观展示趋势
- **每日提醒**：可设置饮水提醒、运动提醒，帮助养成习惯
- **主题切换**：支持浅色/深色主题，提升使用舒适度
- **数据导出**：支持将步数、饮水等数据导出为 CSV，便于备份与回顾

## 5. 数据结构

### 5.1 步数记录表 `step_record`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| date | TEXT | 日期 YYYY-MM-DD |
| steps | INTEGER | 当日步数 |
| goal | INTEGER | 当日目标步数 |

### 5.2 计时记录表 `timer_record`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| start_time | TEXT | 开始时间 |
| end_time | TEXT | 结束时间 |
| duration_sec | INTEGER | 时长（秒） |
| type | TEXT | 正计时/倒计时 |

### 5.3 饮水记录表 `water_record`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| date | TEXT | 日期 YYYY-MM-DD |
| amount_ml | INTEGER | 饮水量（毫升） |
| goal_ml | INTEGER | 当日目标（毫升） |

### 5.4 打卡记录表 `checkin_record`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| date | TEXT | 日期 YYYY-MM-DD |
| checked | INTEGER | 是否打卡 0/1 |

### 5.5 成就记录表 `achievement_record`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| achievement_id | TEXT | 成就 ID |
| unlocked_at | TEXT | 解锁时间 |

## 6. UI/UX 风格

- **色调**：主色偏活力绿/蓝，体现健康与运动；辅色柔和
- **字体**：清晰易读，标题与数字突出
- **布局**：卡片式信息展示，底部导航简洁
- **动效**：步数、饮水进度条有平滑动画；打卡成功有轻反馈
- **弹层**：选择、确认等优先使用底部抽屉（Drawer / Bottom Sheet）
